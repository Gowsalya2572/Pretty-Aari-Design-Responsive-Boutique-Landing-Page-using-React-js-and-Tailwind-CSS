Pretty Aari Design – Responsive Boutique Landing Page

A modern boutique-style landing page designed to showcase handcrafted Aari embroidery collections with an elegant, luxurious, and responsive user experience.

✨ Features
- Elegant boutique-inspired user interface
- Fully responsive design for mobile, tablet, and desktop
- Engaging hero section with call-to-action
- Customized Aari work showcase
- Gallery section featuring previous designs
- Services and order process sections
- Customer testimonials section
- Callback enquiry form integrated with Google Sheets
- Smooth navigation and user-friendly layout
  
🛠️ Tech Stack
- React.js
- Tailwind CSS
- Lucide React Icons
- Google Apps Script
- Google Sheets
  
🎯 Purpose :
This project was developed for a boutique Aari embroidery business to showcase handcrafted designs, highlight services, and 
collect customer enquiries through a callback request form.
