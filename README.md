Pretty Aari Design

A  boutique-style responsive landing page designed for showcasing handcrafted Aari embroidery collections with an elegant and modern user experience.

Features

- Elegant boutique-inspired UI
- Fully responsive design
- Hero section 
- Customized Aari work showcase
- Gallery section for previous designs
- Services and process sections
- Callback enquiry form

  Tech Stack

- React.js
- Tailwind CSS
- Lucide React Icons
